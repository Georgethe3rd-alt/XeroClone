Overview

LoopVybz transforms text news articles into broadcast-quality video content using AI. The platform ingests stories from Caribbean news sources, generates scripts, produces videos with AI video generation, adds TTS narration, and publishes to a public feed.

Key Capabilities

  • Auto-Ingestion — RSS feeds from 9+ Caribbean sources, polled every 15 minutes
  • AI Scripting — Anthropic Claude, OpenAI, Gemini, or Groq generate broadcast scripts
  • Video Generation — D-ID (talking head), Runway ML (story visuals), or Hybrid mode
  • TTS Audio — OpenAI or ElevenLabs narration with category-specific tones
  • Breaking News — Auto-detect and auto-publish urgent stories
  • Multi-tone — Straight News, Conversational, or Youth Voice styles

Quick Start

  1. Log in to the Admin panel
  2. Go to AI Settings — configure your LLM provider (API key + model)
  3. Configure a video provider (D-ID, Runway, or Hybrid)
  4. Configure TTS audio (OpenAI or ElevenLabs)
  5. Go to Sources and enable news feeds
  6. Stories auto-ingest — check Ingested Stories
  7. Create a Post from a story, then click Generate
  8. Review in the Review Queue and publish to LIVE

Managing News Sources

Navigate to Sources. Each source has a name, RSS URL, country, and active toggle. Active sources are polled every 15 minutes. Duplicates are auto-detected via content hashing.

Hybrid Broadcast Mode NEW

Creates professional news broadcasts by combining two AI providers:

┌─────────────┐ ┌──────────────┐ ┌─────────────┐ │ D-ID │ │ Runway ML │ │ D-ID │ │ Anchor Intro│ ──▶ │ Story Scene │ ──▶ │ Anchor Outro│ │ (lip-sync) │ │ (AI visual) │ │ (lip-sync) │ └─────────────┘ └──────────────┘ └─────────────┘ │ │ │ └────────────────────┴────────────────────┘ │ FFmpeg Stitch → Final Broadcast Video

How It Works

  1. AI generates a structured script with segments: [ANCHOR_INTRO], [STORY_VISUAL] with VISUAL description, [ANCHOR_OUTRO]
  2. D-ID generates lip-synced anchor clips for intro and outro
  3. Runway ML generates a visual clip of the actual story scene
  4. FFmpeg normalises and stitches all clips into one broadcast video

Setup

  1. AI Settings → Video Provider → "Hybrid (D-ID Anchor + Runway Story)"
  2. Enter D-ID API key in Video API Key field
  3. Enter Runway API key in Runway API Key field
  4. Select Runway model (gen4_turbo recommended)
  5. Ensure you have an anchor character with an image
💡 Fallback: If Runway fails on a story clip, the system automatically uses a D-ID anchor clip for that segment instead.

Characters & Anchors

Navigate to Characters to manage anchors and public figures.

  • Set one character as Default Anchor with a clear front-facing photo
  • Configure voice settings (provider, voice ID, model) per anchor
  • Add public figures with tags for auto-matching against story text
  • Matched characters' images can be used as Runway prompt images

Review & Publishing

Review Queue shows posts in EDITING status. Preview video, edit headline/caption/category/tags, select thumbnail from 4 candidates, then approve (→ LIVE) or reject (→ DRAFT).

Scheduling & Auto-Publish

  • Schedule a post — Set future publish date; cron checks every 60 seconds
  • Breaking News Auto-Publish — Enable in Settings; "BREAKING"/"URGENT" headlines auto-generate and publish with zero intervention

Analytics

The Analytics page shows: total generations, credit consumption, daily charts, generation times, and engagement metrics (views, likes, saves, shares).

Troubleshooting

Generation fails immediately

  • Check LLM API key validity (Test button in Settings)
  • Ensure video provider key is set
  • Hybrid mode: both D-ID and Runway keys required

Runway videos are generic

  • Use Hybrid mode for story-specific visuals
  • Check that stories have OG images
  • The LLM's videoPrompt drives Runway generation

D-ID lip sync issues

  • Use clear, front-facing photos with good lighting
  • Avoid images with hands near face

No audio on videos

  • Check Audio provider is configured (not "none")
  • Hybrid mode: D-ID segments include their own audio

Generation Pipeline

generateForPost(postId) ├── Fetch post + story ├── Get LLM provider → generate structured script │ → [ANCHOR_INTRO] / [STORY_VISUAL | VISUAL:...] / [ANCHOR_OUTRO] ├── Match characters from story text ├── Get source image (OG → Twitter → img tag → fallback) ├── Proxy image for Runway (→ base64 data URI) ├── Video provider generates video │ ├── D-ID: anchor image + script → lip-synced MP4 │ ├── Runway: story image + visual prompt → AI video │ └── Hybrid: D-ID clips + Runway clip → FFmpeg stitch ├── Generate TTS audio (if video has no audio) ├── Merge audio + video (FFmpeg) ├── Generate 4 thumbnail candidates ├── Upload to storage, create VideoAsset ├── Update post → EDITING └── If breaking + auto_publish → LIVE

Hybrid Provider

File: providers/video/hybrid-news.provider.js

new HybridNewsProvider(didApiKey, runwayApiKey, runwayModel)

// Script parsing: structured markers or auto-split (25%/50%/25%)
// generateAnchorClip() → D-ID talks API
// generateStoryClip() → Runway image-to-video API
// stitchClips() → FFmpeg normalize 720x1280 h264 30fps → concat
// Fallback: if Runway fails, use D-ID anchor for that segment

    thumbnailFilePath: string;
    durationSeconds: number;

Example: Generate a Video

# Login
TOKEN=$(curl -s -X POST http://187.77.217.138:3001/admin/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"admin@example.com","password":"admin123"}' | jq -r .access_token)

# Create post from story
curl -X POST http://187.77.217.138:3001/admin/posts \
  -H "Authorization: Bearer $TOKEN" \
  -d '{"story_id":"STORY_ID","tone":"STRAIGHT_NEWS"}'

# Generate video
curl -X POST http://187.77.217.138:3001/admin/posts/POST_ID/generate \
  -H "Authorization: Bearer $TOKEN"

# Publish
curl -X PATCH http://187.77.217.138:3001/admin/posts/POST_ID/status \
  -H "Authorization: Bearer $TOKEN" \
  -d '{"status":"LIVE"}'
