  OPENCLAW DASHBOARD - DEPLOYMENT INSTRUCTIONS
═══════════════════════════════════════════════════════════

📦 STEP 1: Copy files out of OpenClaw container
───────────────────────────────────────────────────────────
On your host machine:

docker cp <openclaw-container-id>:/data/.openclaw/workspace/apps/dashboard ./dashboard

Replace <openclaw-container-id> with the container ID from:
docker ps | grep openclaw


🚀 STEP 2: Deploy
───────────────────────────────────────────────────────────
cd dashboard
docker-compose up -d --build


✅ STEP 3: Verify
───────────────────────────────────────────────────────────
docker ps | grep dashboard
curl -I http://localhost

🔧 TROUBLESHOOTING
───────────────────────────────────────────────────────────
View logs:
docker logs openclaw-dashboard -f

Restart:
docker-compose restart

Stop:
docker-compose down

Rebuild after changes:
docker-compose up -d --build --force-recreate


📝 CONFIGURATION
───────────────────────────────────────────────────────────
Edit docker-compose.yml to change:
- DASH_PASSWORD (login password)
- PORT (default: 80)
- TELEGRAM_CHAT_ID (your Telegram user ID)

After editing, rebuild:
docker-compose up -d --build
