## Key Learnings

### What Worked
- Incremental merging (imports → endpoints → UI) prevented syntax errors
- Separate testing of each component before integration
- Clear documentation at each step (10+ .md files created)
- Voice notes for Wayne while driving (good UX)

### What Didn't
- Initial wholesale replacement broke advanced features
- First merge attempt had syntax errors (incomplete code blocks)
- Deploying to wrong server wasted time (VPS vs container host)

### Patterns Established
- **Agent spawning**: Use sessions_spawn with label, mode=run, workspace path
- **Personality updates**: Webhook service reads/writes SOUL.md directly
- **Documentation**: marked library for markdown → HTML rendering
- **Message routing**: George messages via inbox, others via spawn queue
